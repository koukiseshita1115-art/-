種目最大重量推定1RM回数

推定1RM は Epley 式（重量 × (1 + 回数/30)）。

自動同期（MCP）

このアプリには Claude 用の MCP サーバーが含まれています。Claude Desktop / Claude Code に登録すると、 このアプリと Claude が同じ記録を共有します。

  • Claude に「今日ベンチ 80kg×8 を 3 セットやった」と話すだけで自動で記録されます（履歴に Claude と表示）。
  • ここで記録した内容も、Claude が読んでメニュー提案や振り返りに使えます。

設定方法は README.md を参照してください。

手動で Claude に渡す

MCP を使わない場合は、記録を Markdown でコピーして Claude のチャットに貼り付けられます。
